3. Description of the Sentra Services

Sentra is a security checkpoint that a Customer's own systems call before performing consequential actions. It provides two primary functions:

  • /evaluate — returns a verdict (allow, contain, or block) and a risk score for a described action, to help the Customer decide whether to proceed.
  • /run_in_seed — executes a Customer-supplied payload inside a sealed, disposable, network-isolated sandbox and returns the observed result.

Nature and limits of the Services. Sentra is a decision-support and containment tool that operates alongside a Customer's existing security controls. It is not a firewall, web application firewall (WAF), antivirus, intrusion prevention system, or a complete security solution, and it does not guarantee that any attack, breach, fraud, unauthorized action, or loss will be prevented or detected. Verdicts are advisory; the Customer remains solely responsible for how it acts on them and for its own security. See also the disclaimers in Section 11.
